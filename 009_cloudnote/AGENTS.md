# 009_CloudNote 作業指示

## GIF・画面操作エビデンス

このプロジェクトは、note・Zenn・WordPress等で技術記事として公開する予定である。静止画だけでなく、操作内容が分かりやすくなる箇所ではGIFも使用する。

各フェーズでGIFとして記録した方が分かりやすい操作を見つけた場合は、ユーザーに必ず次の文言を明示する。

> ここはGIFで記録するのがおすすめです

代表例:

- ログインからホーム画面表示まで
- Notebook / Section / Page の切り替え
- ノート新規作成・編集・自動保存
- タグ追加・検索
- レスポンシブ表示
- エラー発生時の挙動と修正後の正常動作
- Bedrockによる要約、AIによる文章整理、AIタグ生成
- デプロイ後のWebアプリ操作

### 使い分け

- スクリーンショット: AWS設定画面、AWS構成図、Terraform plan結果、DynamoDBテーブル、API Gatewayルート、Lambda設定、CloudWatch Logs、IAM設定
- GIF: ユーザー操作、画面遷移、自動保存、検索、AI処理、UI上の動的な変化

### GIF取得前の安全確認

記録前に、AWSアカウントID、メールアドレス、APIキー、トークン、個人情報、社内情報、IPアドレス、公開すべきでないリソース名が画面に表示されていないことを確認する。映り込む可能性があれば、録画前にユーザーへ知らせる。

GIFを提案する際は、次を簡潔に案内する。

- GIFで操作する機能と、読者に見せたい内容
- 録画開始のタイミング
- 録画終了のタイミング

### 開発ログ

GIFを取得した場合は開発ログに、GIF名、対象機能、取得フェーズ、記事で使用する想定箇所、GIFで説明する内容を記録する。開発完了時には、スクリーンショットとGIFを組み合わせて、そのまま技術記事を作れる状態を目指す。

作業証跡の台帳はExcelで管理する。記事に使う画像を抽出・公開する際は、上記の機密情報確認をあらためて行う。
