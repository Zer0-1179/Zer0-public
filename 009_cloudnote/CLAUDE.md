# 009 CloudNote — プロジェクトメモ

## 状態

2026-08-26に、学習用プロジェクトとしての設計とローカルUI試作を完了した。`frontend/`にはダミーデータだけで動くAstro + React + Tiptapの試作があり、AWSリソース、認証、API、永続化、デプロイは未実装である。`docs/`のAWS構成・実装手順は、時間が取れた際に手動構築Labを行うための設計資料として保持し、実装済みの事実として扱わない。

## 開発の前提

- ノートの階層は Notebook / Section / Page とする。
- 主要機能は、認証、ノート作成・編集・自動保存、タグ、検索である。AI文章補助はMVPの対象外とする。
- 公開用資料は`docs-public/`、非公開の設計・証跡管理資料は`docs/`に置く。
- 作業証跡の原本はExcelで管理し、公開用にマスク済みの画像・GIFだけを`evidence/published/`へ置く。
- AWSリソースの作成、デプロイは、設計の独立レビュー、公式料金確認、費用承認を満たすまで実行しない。
