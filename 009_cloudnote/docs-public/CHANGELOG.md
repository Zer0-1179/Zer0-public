## 2026-08-23

### 個人利用向け費用計画

- 非公開の設計資料に、個人利用・無料枠を差し引かない条件のサービス別コスト見積もりと、AI利用回数別の月額目安を追加した。

### Bedrockモデルの候補レビュー

- 個人利用の初期候補として、Claude Haiku 4.5の日本国内クロスリージョン推論を推奨する設計判断を追加した。最新世代の高性能モデルは、必要時だけ比較対象とする。

### MVPの対象を手動整理へ変更

- AI機能とAmazon BedrockをMVP対象外とし、Notebook / Section / Page、タグ、検索、自動保存による手動整理へ対象を絞った。
- Codex連携は、権限と操作範囲を限定した専用APIとして将来課題に分離した。
- 構成図の一次情報源であるdraw.ioからBedrockを外した。PNG・SVGは利用者がdraw.ioから再出力する。
