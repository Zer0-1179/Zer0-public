# AWS公式アイコン

`009_architecture.drawio`と`009_architecture.svg`で使用するAWSサービスアイコンである。

- 取得元: [AWS Architecture Icons](https://aws.amazon.com/jp/architecture/icons/)
- パッケージ版: 2026-01-30
- 取得日: 2026-08-22
- 対象: Amazon CloudFront、Amazon Cognito、Amazon S3、Amazon API Gateway、AWS Lambda、Amazon DynamoDB、Amazon CloudWatch

図の可搬性のため、draw.ioには同一アイコンをPNG形式の`data:image/png,`として埋め込んでいる。draw.ioのスタイル文字列では`;`が区切り文字のため、`data:image/png;base64,`は使用しない。外部ファイル参照に依存しないため、draw.ioで開いた際にもアイコンが表示される。このフォルダはアイコンの出所確認と更新時の差し替え用に保持する。
