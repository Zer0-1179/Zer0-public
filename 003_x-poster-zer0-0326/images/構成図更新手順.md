# 構成図（003_architecture）更新手順

draw.ioで `003_architecture_plugin.drawio` を編集してからサイトに反映するまでの手順。
上から順にコピペで実行すればOK（3以降はClaude Codeにそのまま依頼してもよい）。

## 1. draw.ioアプリで編集・保存

`003_x-poster_zer0-0326/images/003_architecture_plugin.drawio` をdraw.ioデスクトップアプリで開いて編集 → 保存（Ctrl+S）。

## 2. SVGエクスポート（draw.ioアプリ内で操作・手動）

draw.ioアプリのメニューから `ファイル → エクスポート → SVG...` を実行し、
**同じimagesフォルダに `003_architecture_plugin.drawio.svg` という名前で上書き保存**する。
（このファイルが無いとこの後のスクリプトは失敗する）

## 3. 通信アニメーション付きSVG + PNGサムネイルを生成

Windowsのcmdからそのまま貼り付けでOK（`wsl`経由でWSL側のpython3が動く）。

```
wsl python3 /root/Zer0/003_x-poster_zer0-0326/images/build_architecture_flowdot.py
wsl python3 /root/Zer0/003_x-poster_zer0-0326/images/export_architecture_png.py
```

**この2つとも実行すること。** サイトの一覧・詳細ページはデフォルトで`003_architecture.png`（軽い静止画）を表示し、
`003_architecture.svg`（アニメーション付き）はクリックしたズーム表示でしか使われない
（`src/src/components/ImageLightbox.astro`参照）。SVGだけ更新してPNGを忘れると、
本番は正しくデプロイされているのに見た目は「変わっていないように見える」現象が起きる（キャッシュの問題ではない）。

`003_architecture_plugin_flowdot.svg` と `003_architecture.png` が再生成される。

## 4. ポートフォリオサイトへ反映

WSL/Linux側（Claude Codeのbash等）で実行。**svgとpng両方をコピーすること。**

```bash
cp /root/Zer0/003_x-poster_zer0-0326/images/003_architecture_plugin_flowdot.svg \
   /root/Zer0/004_portfolio/src/public/images/003_architecture.svg
cp /root/Zer0/003_x-poster_zer0-0326/images/003_architecture.png \
   /root/Zer0/004_portfolio/src/public/images/003_architecture.png
cd /root/Zer0/004_portfolio && bash scripts/deploy.sh
```

## 5. デプロイ確認（本番とローカルのMD5一致チェック、svg・png両方）

```bash
curl -s https://www.zer0-infra.com/images/003_architecture.svg | md5sum
md5sum /root/Zer0/004_portfolio/src/public/images/003_architecture.svg
curl -s https://www.zer0-infra.com/images/003_architecture.png | md5sum
md5sum /root/Zer0/004_portfolio/src/public/images/003_architecture.png
```

## 6. Gitへ同期

```bash
bash /root/Zer0/sync_to_public.sh
```
