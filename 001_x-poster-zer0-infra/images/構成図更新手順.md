# 構成図（001_architecture）更新手順

draw.ioで `001_architecture_plugin.drawio` を編集してからサイトに反映するまでの手順。
上から順にコピペで実行すればOK（3以降はClaude Codeにそのまま依頼してもよい）。

## 1. draw.ioアプリで編集・保存

`001_x-poster_zer0-infra/images/001_architecture_plugin.drawio` をdraw.ioデスクトップアプリで開いて編集 → 保存（Ctrl+S）。

## 2. SVGエクスポート（draw.ioアプリ内で操作・手動）

draw.ioアプリのメニューから `ファイル → エクスポート → SVG...` を実行し、
**同じimagesフォルダに `001_architecture_plugin.drawio.svg` という名前で上書き保存**する。
（このファイルが無いとこの後のスクリプトは失敗する）

### 2'. （代替）draw.io CLIでエクスポートする場合

Claude Code等からWSL側で実行する場合は、Windows版draw.ioのCLIでも同じSVGを書き出せる（2026-10-25に実施）。

```bash
W=/mnt/c/Users/<Windowsユーザー名>/AppData/Local/Temp/drawio001 && mkdir -p $W && \
cp /root/Zer0/001_x-poster_zer0-infra/images/001_architecture_plugin.drawio $W/ && \
"/mnt/c/Program Files/draw.io/draw.io.exe" -x -f svg \
  -o 'C:\Users\<Windowsユーザー名>\AppData\Local\Temp\drawio001\out.drawio.svg' \
  'C:\Users\<Windowsユーザー名>\AppData\Local\Temp\drawio001\001_architecture_plugin.drawio' && \
cp $W/out.drawio.svg /root/Zer0/001_x-poster_zer0-infra/images/001_architecture_plugin.drawio.svg && rm -rf $W
```

**注意**: CLIで書き出したSVGには、図の下端に「Text is not SVG - cannot display」という警告リンク（`<switch>`内の`svg-export-text-problems`へのリンク）が入る。手順3の`build_architecture_flowdot.py`の実行後、PNGを作る前に`001_architecture_plugin_flowdot.svg`からこの`<switch>`要素を削除すること（残すとPNGの下端に警告文が写る）。

## 3. 通信アニメーション付きSVG + PNGサムネイルを生成

Windowsのcmdからそのまま貼り付けでOK（`wsl`経由でWSL側のpython3が動く）。

```
wsl python3 /root/Zer0/001_x-poster_zer0-infra/images/build_architecture_flowdot.py
wsl python3 /root/Zer0/001_x-poster_zer0-infra/images/export_architecture_png.py
```

**この2つとも実行すること。** サイトの一覧・詳細ページはデフォルトで`001_architecture.png`（軽い静止画）を表示し、
`001_architecture.svg`（アニメーション付き）はクリックしたズーム表示でしか使われない
（`src/src/components/ImageLightbox.astro`参照）。SVGだけ更新してPNGを忘れると、
本番は正しくデプロイされているのに見た目は「変わっていないように見える」現象が起きる（キャッシュの問題ではない）。

`001_architecture_plugin_flowdot.svg` と `001_architecture.png` が再生成される。

## 4. ポートフォリオサイトへ反映

WSL/Linux側（Claude Codeのbash等）で実行。**svgとpng両方をコピーすること。**

```bash
cp /root/Zer0/001_x-poster_zer0-infra/images/001_architecture_plugin_flowdot.svg \
   /root/Zer0/004_portfolio/src/public/images/001_architecture.svg
cp /root/Zer0/001_x-poster_zer0-infra/images/001_architecture.png \
   /root/Zer0/004_portfolio/src/public/images/001_architecture.png
cd /root/Zer0/004_portfolio && bash scripts/deploy.sh
```

## 5. デプロイ確認（本番とローカルのMD5一致チェック、svg・png両方）

```bash
curl -s https://www.zer0-infra.com/images/001_architecture.svg | md5sum
md5sum /root/Zer0/004_portfolio/src/public/images/001_architecture.svg
curl -s https://www.zer0-infra.com/images/001_architecture.png | md5sum
md5sum /root/Zer0/004_portfolio/src/public/images/001_architecture.png
```
